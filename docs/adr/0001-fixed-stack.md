# 0001. Фиксированный стек на все этапы

- Статус: accepted
- Дата: 2026-11-17

## Контекст

Проект ведёт один человек. Каждая лишняя технология увеличивает стоимость поддержки, а смена стека между этапами означает переписывание.

## Решение

Стек не меняется на этапах 1–3: Python + FastAPI, SQLAlchemy async, ARQ + Redis, PostgreSQL + pgvector, LangChain, OpenRouter, React + TypeScript + Vite + Tailwind + shadcn/ui, Railway, Docker Compose для локальной работы.

## Альтернативы

- Django: готовая админка, но тяжелее для async и RAG; админка всё равно делается отдельным интерфейсом.
- Отдельная векторная БД (Pinecone, Chroma): ещё один сервис и ещё одни бэкапы без выигрыша на нашем объёме (3–5 книг).
- Vue: меньше примеров интеграций для Telegram Mini App, чем у React.

## Последствия

Добавление или замена технологий требует нового ADR и согласия владельца. Агенты обязаны соблюдать это правило (`.cursor/rules/00-product-and-stack.mdc`).
