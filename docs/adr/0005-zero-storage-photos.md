# 0005. Фото ладоней не сохраняются

- Статус: accepted
- Дата: 2026-11-17

## Контекст

Фото рук — персональные данные. Обещание «мы не храним ваши фото» — часть доверия к продукту и снижает юридические риски на старте без юрлица.

## Решение

Фото передаётся от Mini App в API, кладётся в Redis с TTL 30 минут и удаляется воркером сразу после чтения. Не пишется на диск, в БД, логи и аналитику. Дальше используются только текстовые признаки.

## Альтернативы

- Хранить фото для повторного анализа: удобнее, но противоречит обещанию продукта.
- Обрабатывать в API без очереди: проще, но блокирует запрос и не переживает перезапуск.

## Последствия

- Если воркер упал, задачу нельзя повторить автоматически: пользователь загружает фото снова.
- Ревью (Bugbot, `privacy-auditor`) отдельно проверяет любые изменения, затрагивающие фото.
- При подключении внешнего CV-подрядчика фото уходит ему; нужен договор и отражение в политике конфиденциальности.
