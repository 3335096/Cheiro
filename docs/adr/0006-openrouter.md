# 0006. LLM и эмбеддинги через OpenRouter

- Статус: accepted
- Дата: 2026-11-17

## Контекст

Модель для отчётов нужно менять без изменения кода (качество, цена, доступность из РФ). Нужны и генерация, и эмбеддинги.

## Решение

Один OpenAI-совместимый шлюз OpenRouter для LLM (`LLM_MODEL`) и эмбеддингов (`EMBEDDING_MODEL`). LangChain используется как тонкий слой. Для эмбеддингов отправляется чистый текст (`check_embedding_ctx_length=False`), асинхронные вызовы.

## Альтернативы

- Прямые API провайдеров: несколько ключей и SDK, сложнее переключать модели.
- Локальные модели: нет ресурсов на хостинге этапа 1.

## Последствия

- Смена LLM = смена переменной (позже из админки).
- Смена модели эмбеддингов с другой размерностью = миграция и переиндексация (см. [ADR 0002](0002-postgres-pgvector.md)).
- Зависимость от доступности шлюза; ошибки провайдера фиксируются в статусе источника или задачи.
