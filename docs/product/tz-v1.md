# Техническое задание — CHEIRO (v1 scope)

Полная исходная спецификация (рабочее название Sheira) сужена до **этапа 1**, см. [границы этапов](scope-and-stages.md).

## 1. Общая информация

**CHEIRO** — Telegram Mini App с AI и RAG для анализа линий руки на основе профессиональной литературы по хиромантии.

- Аудитория: пользователи Telegram (самопознание, психология).
- Корпус старта: 3–5 книг, русский и английский, EPUB и PDF (в т.ч. сканы с OCR).

## 2. Архитектура (неизменный стек)

См. [архитектуру](../architecture/overview.md), [ADR](../adr/README.md) и [границы этапов](scope-and-stages.md).

## 3. Функциональные требования — этап 1

### 3.1 RAG Foundation (приоритет №1)

1. Загрузка EPUB/PDF в админке.
2. OCR для PDF-сканов (очередь, платный API).
3. Очистка, чанкинг с метаданными (книга, автор, язык).
4. Векторизация в pgvector, привязка к источнику.
5. Retrieval + генерация ответа (OpenRouter), цитирование источников в отладке/админке.
6. Набор регрессионных тест-вопросов (`backend/evals/rag_golden.json`).

### 3.2 Telegram Mini App

1. Onboarding.
2. Загрузка фото (камера/галерея), рамка ладони.
3. Анимация анализа (статусы job).
4. **Тизер** (1–2 предложения) — v1 без paywall; полный отчёт в боте (этап 1: бесплатно для теста продукта).

### 3.3 Admin Dashboard

1. Управление книгами и статусом индексации.
2. Prompt Studio (system prompt, model id).
3. Просмотр качества RAG (golden questions).

### 3.4 Telegram Bot

1. Создание с нуля: `/start`, deep link в Mini App, доставка полного отчёта.

## 4. Нефункциональные

- UI: чистый минимализм, бренд CHEIRO (типографика + акцентная точка).
- Zero-storage фото пользователя (обработка в памяти воркера).
- SLA генерации: ≤ 45 с (целевое).
- Политики privacy/terms — тексты-заглушки в `docs/legal/` до юрлица.

## 5. Вне scope v1

- CloudPayments, Astro API, zhivo.crm (только env-задел).
- Несколько платных продуктов, подписки, bulk-отчёты.
