# Корпус знаний

Реестр книг в индексе. Добавляйте строку при каждой загрузке (скил `add-rag-source`).

| Название | Автор | Язык | Формат | Происхождение / права | Добавлена | Статус |
|----------|-------|------|--------|----------------------|-----------|--------|
| _пока пусто_ | | | | | | |

Правила:

- Фиксируйте происхождение файла и права на использование.
- PDF-сканы требуют OCR (`OCR_PROVIDER`); сначала загружайте книги с текстовым слоем.
- После добавления книги расширьте golden-набор и прогоните `npm run eval`.
