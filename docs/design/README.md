# Дизайн CHEIRO

Стиль: чистый, лаконичный, профессиональный минимализм. Упор на юзабилити; без «мультяшных» элементов.

## Принципы

1. **Ясность важнее украшений.** Один главный экран, одно главное действие.
2. **Спокойный тон.** Нейтральная палитра и один акцентный цвет; акцент несёт смысл (главное действие, статус), а не декор.
3. **Бренд:** слово CHEIRO с акцентной точкой (компонент `BrandMark`).
4. **Обратная связь всегда:** состояния loading / error / empty / success продуманы на каждом экране.
5. **Доступность:** контраст WCAG AA, зоны касания ≥ 44 px, видимый фокус, подписи у полей.
6. **Telegram first (Mini App):** тема из Telegram (светлая и тёмная), `MainButton`/`BackButton`, safe-area, ширина 360–430 px.
7. **Админка:** плотный информативный интерфейс: боковая навигация, таблицы со статусами, подтверждение опасных действий.

## Технологии

Tailwind CSS и компоненты в духе shadcn/ui (Radix). Токены (цвет, типографика, отступы, радиусы, тени) задаются в одном месте и общие для Mini App и админки.
