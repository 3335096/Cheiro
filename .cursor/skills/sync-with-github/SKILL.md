# Синхронизация компьютер ↔ GitHub ↔ облачные агенты

Принцип: **GitHub — источник правды**; ничего не затирается.

1. `npm run sync`. Скрипт делает `fetch`, обновляет текущую ветку (rebase, только если нет несохранённых изменений) и показывает:
   - ветки облачных агентов (`origin/cursor/*`) с неслитой работой;
   - локальные ветки, которых нет на GitHub.
2. **Есть несохранённые изменения** → закоммить или `git stash`, затем снова `npm run sync`.
3. **Нужно забрать работу облачного агента:** открой его PR на GitHub; либо локально `git checkout <имя ветки>` (без `origin/`), проверь `npm run check`.
4. **Конфликт при rebase:** прочти обе стороны, объедини смысл (не «возьми свою/чужую»), `git rebase --continue`; при сомнении `git rebase --abort` и спроси владельца.
5. **Смена устройства:** скил `handoff-work`. На устройстве, где лежат файлы, фраза «закончил работу» коммитит и пушит ветку. На другом устройстве фраза «продолжи ветку <имя>» забирает её с GitHub.
6. **После слияния PR:** `git checkout main && git pull`, удалить локальную ветку (`git branch -d`).
7. Запрещено: `git push --force`, `git reset --hard` по чужой работе, прямые коммиты в `main`.
