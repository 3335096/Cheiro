# ADR

1. Найди следующий номер в `docs/adr/` (`NNNN-короткое-название.md`, нумерация сквозная).
2. Скопируй `docs/adr/0000-template.md`.
3. Заполни:
   - **Контекст:** какая проблема, какие ограничения (один разработчик, неизменный стек, этапы).
   - **Решение:** что выбрано, одной-двумя фразами.
   - **Альтернативы:** 2–3 варианта и почему отвергнуты.
   - **Последствия:** плюсы, цена, что придётся делать (миграция, переиндексация, документация).
4. Статус `proposed`; станет `accepted` после согласия владельца. Заменённое решение получает `superseded by NNNN`.
5. Добавь запись в индекс `docs/adr/README.md` и строку в `CHANGELOG.md`, если решение меняет поведение.
