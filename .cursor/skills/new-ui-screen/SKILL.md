# Новый или изменённый экран

Перед началом прочитай `docs/design/` (токены и принципы) и правило `40-frontend-ui-ux`.

1. **Цель экрана** одной фразой и главное действие пользователя. Лишнее убери.
2. **Состав:** используй готовые компоненты и токены. Новый компонент добавляй в общую библиотеку, а не внутрь страницы.
3. **Состояния:** loading (skeleton), error (причина + повторить), empty (что делать дальше), success. Реализуй все.
4. **Mini App:** тема Telegram (светлая и тёмная), `MainButton`/`BackButton` где уместно, safe-area, ширина 360–430 px, нет горизонтального скролла.
5. **Админка:** таблицы с фильтрами и статусами, подтверждение опасных действий, работа с клавиатуры.
6. **Доступность:** контраст AA, зоны касания ≥ 44 px, подписи у полей, фокус виден, `aria-*` у нестандартных элементов.
7. **Тексты:** ясные, короткие, на русском; готовы к локализации.
8. **Тест:** vitest + Testing Library на ключевое поведение (действие пользователя → результат).
9. **Проверка:** `npm run check:frontend`; запусти приложение и пройди экран глазами в обеих темах, на узкой ширине; сделай скриншоты для PR.
10. Привлеки субагента `ui-reviewer` на финальный просмотр. Обнови `docs/design/` если появился новый паттерн.
