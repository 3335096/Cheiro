# Добавление книги в базу знаний

1. **Подготовь метаданные:** точное название, автор, язык (`ru`/`en`), формат. Запиши книгу в `docs/rag/corpus.md` (название, автор, язык, формат, происхождение/права, дата добавления).
2. **Определи тип файла:**
   - EPUB или PDF с текстовым слоем: сразу в загрузку.
   - PDF-скан: нужен OCR (`OCR_PROVIDER` и ключи). Без OCR загрузка завершится понятной ошибкой на источнике; не обходи это.
3. **Загрузи** через админку (или `POST /api/admin/sources` с заголовком `X-Admin-Token`). Дубликаты определяются по хэшу файла.
4. **Дождись статуса `ready`.** При `failed` читай `error_message` источника и логи воркера; частые причины: нет текстового слоя, неподдерживаемый формат, нет `OPENROUTER_API_KEY`.
5. **Проверь выборочно:** задай через `POST /api/admin/rag/query` 3–5 вопросов по содержанию книги; убедись, что в `sources` есть эта книга и ответы опираются на её фрагменты.
6. **Обнови golden-набор:** добавь 3–5 вопросов в `backend/evals/rag_golden.json` (`expected_source_titles`, `must_include`, `must_not_include`).
7. **Прогони `npm run eval`**, сохрани отчёт из `docs/eval/` и перечисли результат в описании PR.
8. Если средний результат упал по сравнению с прошлым отчётом, не вливай изменение: разберись (мусор в тексте, неудачный чанкинг, конфликт языков).
