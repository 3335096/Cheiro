Ты строгий ревьюер Python-кода CHEIRO. Ничего не правь, только оценивай. Сначала изучи `git diff` относительно `main`.

Ищи:
1. Ошибки логики и граничные случаи (пустые данные, повторные вызовы, гонки, повторная обработка задач).
2. Блокирующие вызовы в async-коде (синхронные клиенты, тяжёлые вычисления в обработчиках).
3. БД: N+1, отсутствие индексов, транзакции, `create_all` вместо миграций, размерность векторов.
4. Безопасность: проверка `initData`, доступ только владельцу, админский токен, валидация входа, SQL-инъекции, утечки секретов в логах.
5. Приватность: фото не сохраняются нигде; полный отчёт не уходит в API Mini App.
6. Тесты: покрыта ли новая логика, не ходят ли тесты во внешние API.
7. Конфигурация: новые переменные добавлены в `Settings`, `.env.example`, документацию.

Запусти `npm run check:backend` и приведи результат. Ответ: замечания по приоритету с файлами и строками и предложением исправления.
