# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Записи пользовательским языком.

## [Unreleased]

### Добавлено
- Передача работы между устройствами: фразы «закончил работу локально» и «продолжи ветку» публикуют и забирают ветку на GitHub без ручных команд git (скил `handoff-work`).
- Основа проекта CHEIRO: конвейер RAG (загрузка EPUB/PDF, чанкинг, эмбеддинги, поиск по pgvector), анализ ладони с тизером в Mini App и полным отчётом в боте, прототип интерфейсов и админки.
- Проверки качества: ruff, mypy, pytest (в том числе интеграционные на pgvector), oxlint, prettier, vitest; единая команда `npm run check`; CI в GitHub Actions; сканирование секретов.
- Инструмент оценки RAG: `npm run eval` с golden-набором и Markdown-отчётами.
- Настройка Cursor: `AGENTS.md`, правила, скилы, субагенты, хуки, правила Bugbot, окружение облачных агентов.
- Кроссплатформенные команды для Windows: `npm run setup`, `dev`, `check`, `fix`, `eval`, `sync`.
- Структура документации `docs/`, ADR, runbook для локальной работы, Railway и GitHub.

### Исправлено
- Загрузка EPUB не работала (библиотека не читает данные из памяти).
- Запросы эмбеддингов к OpenRouter отправляли токены вместо текста и блокировали цикл событий воркера.
- Статус анализа был доступен любому, кто знает идентификатор задачи; теперь только владельцу, и без полного отчёта.
- Вне режима отладки приложение больше не стартует с токеном админки по умолчанию или без токена бота.
- Адрес базы данных вида `postgresql://` (формат Railway) автоматически приводится к драйверу asyncpg.
- Frontend в Docker на Windows: отдельный том для `node_modules` и polling для горячей перезагрузки.
